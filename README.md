Smart Farm Management System

Project Description

The Smart Farm Management System is a C++ project designed to manage crop information, calculate crop yields, compare crop production, and provide farming advice.

Features

- Crop information management
- Total yield calculation
- Yield comparison
- Farming advice
- File handling
- Exception handling

OOP Concepts Used

- Classes and Objects
- Inheritance
- Abstraction
- Runtime Polymorphism
- Operator Overloading
- Constructors and Destructors
- Static Members

Programming Language

C++

Project Files

- main.cpp – Main C++ source code
- crops.txt – Saved crop information
- output.png – Program execution screenshot

How to Run

Compile:
g++ -std=c++11 main.cpp -o farm.exe

Run:
.\farm.exe
